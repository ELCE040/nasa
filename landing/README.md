# NAYSA Sport landing page

This is a standalone React/Vite landing page. It does not replace the team portal.

## Commands

Run `npm install`, then `npm run dev` during development. Run `npm run build` to create the deployable site in `dist/`.

The page uses React Bits-style reusable motion components (`AnimatedContent`, `BlurText`, and `ShinyText`) alongside Lucide React icons. The Android download remains `/downloads/naysa-sport.apk`; team actions remain at `/portal/`.
